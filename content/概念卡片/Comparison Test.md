# Comparison Test

## Core Sentence / 核心句

The Comparison Test uses larger/smaller positive series to infer convergence or divergence.

中文理解：比较判别法靠大小关系传递收敛或发散。

## Formula / 公式或规则

If $0<a_n\le b_n$:

- $\sum b_n$ converges $\Rightarrow \sum a_n$ converges
- $\sum a_n$ diverges $\Rightarrow \sum b_n$ diverges

## When To Use / 什么时候用

看到 positive series 和明显大小关系，就用 comparison test。

## Watch Out / 易错点

方向不能反：小发散推大发散，大收敛推小收敛。
