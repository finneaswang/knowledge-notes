# Point Charge

## Core Sentence / 核心句

A point charge treats a charged object as if all charge were concentrated at one point.

中文理解：点电荷模型忽略物体大小，只保留电荷量和位置。

## Formula / 公式或规则

$$E=k\frac{|Q|}{r^2}$$

## When To Use / 什么时候用

看到 isolated small charge、distance much larger than object size，就可用 point charge。

## Watch Out / 易错点

连续带电体不能随便当点电荷，除非有合适近似或对称结论。
