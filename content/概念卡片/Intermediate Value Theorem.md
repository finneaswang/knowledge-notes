# Intermediate Value Theorem

## Core Sentence / 核心句

A continuous function on a closed interval must attain every output value between its endpoint outputs.

中文理解：连续函数不能从一个端点高度跳到另一个端点高度；中间的每个函数值都必须经过。

## Hypothesis / 前提

$$
f\text{ is continuous on }[a,b].
$$

## Conclusion / 结论

If $L$ lies between $f(a)$ and $f(b)$, then there exists $c\in[a,b]$ such that

$$
f(c)=L.
$$

## Watch Out / 易错点

- IVT guarantees existence, not uniqueness.
- It does not locate $c$.
- It does not require differentiability.
- It concerns function values, not derivative values.
