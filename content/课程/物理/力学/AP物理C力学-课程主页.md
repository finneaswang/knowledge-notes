# AP物理C力学 - 课程主页

## Reading Guide / 阅读说明

这是 [[AP Physics C Mechanics]] 的课程主页，与 [[AP电磁学第1次正课-电荷库仑定律与电场|AP Physics C Electricity and Magnetism]] 并列。笔记以课堂 transcript 为主线，英文保留物理定义与可直接用于作答的句子，中文负责解释、推导和易错点。

## Course Spine / 课程主轴

```text
calculus tools
-> kinematics: describe motion
-> forces and translational dynamics: explain changes in motion
-> work and energy
-> linear momentum
-> rotation and angular momentum
-> oscillations
```

核心因果链：

```text
position -> velocity -> acceleration <- net force
```

- 左侧是微积分描述：[[Position and Displacement]] -> [[Velocity and Speed]] -> [[Acceleration]]。
- 右侧是动力学解释：[[Newton's Second Law]] 把 net force 与 acceleration 连接起来。

1. [[AP物理C力学Orientation-课程结构与学习地图]]
   - 七个单元、课程逻辑、力学中微积分的角色。
2. [[AP物理C力学预备课-微积分工具]]
   - derivative 读瞬时变化，integral 读累积变化。
3. [[AP物理C力学第1次正课-位移速度加速度与运动图像]]
   - vectors、位移与路程、速度与速率、运动图像、匀加速与自由落体。
4. [[AP物理C力学第2次正课-抛体相对运动与力的开端]]
   - 竖直上抛、二维抛体、相对速度、常见力与 free-body diagram 开端。
5. [[AP物理C力学第3次正课-牛顿定律摩擦弹簧与系统法]]
   - Newton's laws、受力图规范、静/动摩擦、Hooke's law 与整体法。
6. [[AP物理C力学第4次正课-连接体阻力与圆周运动入门]]
   - 理想绳轮约束、斜面连接体、速度相关阻力、terminal velocity 与圆周运动入口。
7. [[AP物理C力学第5次正课-圆周运动万有引力与质心]]
   - 锥摆、平面/倾斜转弯、竖直圆周、万有引力、shell theorem 与 center of mass。
8. [[AP物理C力学第6次正课-功功率势能与机械能守恒]]
   - work、power、work-energy theorem、potential energy、机械能守恒与势能曲线。
9. [[AP物理C力学第7次正课-能量综合势能曲线与动量入门]]
   - 能量综合模型、loop-the-loop、势能曲线读图与 linear momentum 入口。
10. [[AP物理C力学第8次正课-冲量动量守恒与碰撞]]
   - impulse-momentum theorem、系统动量守恒、二维碰撞、质心运动和碰撞分类。
11. [[AP物理C力学第9次正课-转动运动学力矩与转动惯量]]
   - 转动运动学、角量与线量、torque、静力平衡、rotational inertia 与平行轴定理。
12. [[AP物理C力学第10次正课-转动能量角动量与守恒]]
   - rotational work-energy、angular impulse、angular momentum 与转盘守恒模型。
13. [[AP物理C力学第11次正课-滚动天体运动与简谐振动开端]]
   - 无滑/有滑滚动、轨道运动、Kepler's laws、escape speed 与 SHM 开端。
14. [[AP物理C力学第12次正课-简谐振动弹簧摆与共振]]
   - SHM 方程、图像、能量、水平/竖直弹簧、三类摆与 resonance。
15. [[AP物理C力学第13次正课-FRQ实验线性化与作图规范]]
   - experimental linearization、坐标单位、best-fit line、斜率与实验误差链。
16. [[AP物理C力学第14次正课-FRQ综合推导实验与表达策略]]
   - symbolic derivation、representation translation、实验设计和 scientific justification。
17. [[AP物理C力学串讲课-全课程模型与方法总复盘]]
   - 14 次正课后的模型选择、定律边界与全课程快速恢复入口。
