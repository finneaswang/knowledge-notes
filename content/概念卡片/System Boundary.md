# System Boundary

## Core Sentence / 核心句

A system boundary determines which interactions are internal and which transfers cross the boundary.

中文理解：边界不是画图形式，而是决定方程里哪些力会抵消、哪些能量以 work 进入或离开。

## When To Use / 什么时候用

- connected bodies：整体求共同运动，隔离局部求内力；
- energy：决定 gravity/spring 是 external work 还是 internal potential energy；
- momentum：只有 external impulse 改变系统总动量。

## Watch Out / 易错点

换 system 后必须重写 external/internal 分类；不能在同一账本中重复计算同一 interaction。
