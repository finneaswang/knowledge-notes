# Limit Comparison Test

## Core Sentence / 核心句

The Limit Comparison Test compares end behavior through a ratio limit.

中文理解：极限比较法用两个级数项的比值判断尾部行为是否同阶。

## Formula / 公式或规则

$$\lim_{n\to\infty}\frac{a_n}{b_n}=c,\quad 0<c<\infty$$

then both series share convergence behavior.

## When To Use / 什么时候用

看到 rational expression、dominant terms、same end behavior，就用 limit comparison。

## Watch Out / 易错点

极限是 0 或无穷时不能直接用这个结论。
