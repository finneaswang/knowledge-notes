# Lagrange Error Bound

## Core Sentence / 核心句

The Lagrange Error Bound controls how far a Taylor polynomial can be from the actual function.

中文理解：拉格朗日误差界告诉你 Taylor polynomial 近似函数时最多错多少。

## Formula / 公式或规则

$$
|R_n(x)|\le \frac{M}{(n+1)!}|x-c|^{n+1}
$$

## When To Use / 什么时候用

看到 Taylor polynomial error、maximum error、bound，就用 Lagrange Error Bound。

## Watch Out / 易错点

$M$ 要控制的是下一阶导数在区间上的最大值。
