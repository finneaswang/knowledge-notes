# Exponential Functions

## Core Sentence / 核心句

An exponential function turns additive changes in its input into multiplicative changes in its output.

中文理解：输入每增加相同的量，输出就乘以相同的倍数；这就是指数函数的结构核心。

## Formula / 公式

$$
f(x)=a^x,\qquad a>0
$$

$$
a^{x+h}=a^xa^h
$$

$$
\frac{d}{dx}a^x=(\ln a)a^x
$$

## Memory Sentence / 记忆句

Every exponential function has a derivative proportional to itself.

中文：指数函数越大，它的绝对变化速度也按同一比例越大。

## When To Use / 什么时候用

看到 constant percentage growth、repeated multiplication、doubling、half-life 或 $y'=ky$ 时，考虑 exponential model。

## Watch Out / 易错点

- $a^x$ 的导数不是总等于 $a^x$；必须乘 $\ln a$。
- $a^x$ 与 $x^a$ 的变量位置不同，求导规则不同。
- 指数模型表达 constant relative rate，不是 constant absolute increase。
