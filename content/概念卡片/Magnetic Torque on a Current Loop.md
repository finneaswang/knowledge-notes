# Magnetic Torque on a Current Loop

## Core Sentence / 核心句

A uniform magnetic field can exert zero net force but nonzero torque on a current loop.

中文理解：线圈两侧的磁力可以等大反向而使合力为零，但作用线不同会形成力偶，使线圈转动。

## Magnetic Dipole Moment / 磁偶极矩

$$
\boxed{
\vec\mu=NIA\hat n
}
$$

right-hand fingers curl with current；thumb gives $\hat n$ and $\vec\mu$。

## Torque / 力矩

$$
\boxed{
\vec\tau=\vec\mu\times\vec B
}
$$

$$
\boxed{
\tau=NIAB\sin\theta
}
$$

$\theta$ 是 $\vec\mu$ 与 $\vec B$ 的夹角。

## Orientation / 方位

- $\vec\mu\perp\vec B$：maximum torque；
- $\vec\mu\parallel\vec B$：zero torque, stable orientation；
- $\vec\mu$ antiparallel $\vec B$：zero torque, unstable orientation。

potential energy：

$$
\boxed{
U=-\vec\mu\cdot\vec B
}
$$

## Motor Bridge / 电动机连接

motor 通过 current loop 的 magnetic torque 产生 rotation。DC brushed motor 的 commutator 周期性反转 current，以维持同一 torque direction。

## Watch Out / 易错点

- angle 不是 loop plane 与 field 的夹角。
- torque zero 不代表 angular speed zero。
- net force zero 不代表 torque zero。
- total turns 用 $N$，single-loop area 用 $A$。
