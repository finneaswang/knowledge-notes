# Angular Momentum
## Core Sentence / 核心句
Angular momentum is rotational momentum defined about a chosen point or axis.
$$\vec L=\vec r\times\vec p,\qquad L=I\omega\ \text{for a rigid body about a fixed axis}$$
## Watch Out / 易错点
reference point/axis 改变，$L$ 也可能改变。
