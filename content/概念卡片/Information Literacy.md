# Information Literacy

> **Information literacy is the ability to find, identify, evaluate, use, and acknowledge information according to a specific purpose.**
>
> 信息素养是根据任务需求找到、识别、评估、使用并说明信息来源的能力。

## Working Cycle

~~~text
information need -> search -> inspect -> evaluate -> use -> cite -> revise the need
~~~

这是循环而不是单向流程：读到新 source 后，你可能会改写 research question、更换 keywords 或追踪新引用。

## What It Is Not

- 不是搜索结果越多越好；
- 不是看到 peer-reviewed 就停止判断；
- 不是把 citation format 背下来就完成 research；
- 不是由 Google、Summon 或 GenAI 替你决定什么值得信。
