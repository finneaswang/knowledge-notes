# 串讲课

## Core Sentence / 核心句

串讲课 is a review-style lesson that connects earlier topics into exam routines.

中文理解：串讲课不是新章节，而是把知识点按考试路线串起来。

## Formula / 公式或规则

Course workflow card.

## When To Use / 什么时候用

用于标记复习课、综合课、考前整理课。

## Watch Out / 易错点

不要把它当具体知识点。
