## Longitudinal Finding / 纵向变化

### 已经进步的部分

- 第1次作业中，困难主要发生在“这是什么题型”；第2次已经能独立启动多数 Power / Product / Chain / Quotient computations。
- 第2次的 FRQ 41、42 最终数学结果正确，说明公式、表格、图像和英文句子可以被组织进同一答案。
- 第3次已经能在 FRQ 中连续完成 tangent approximation、related rates 与 second-order contextual meaning；第40、41题显示“rate of a rate”的理解明显进步。
- 发现答案与选项不匹配时，会回头检查原式，并多次识别出 AI 把 $xy^3$、$y^3$、$e^2$、$e^y$ 看错。这是有效的 mathematical verification habit。

### 仍然反复出现的部分

1. **Object identification / 先确认对象是谁**
   - 图给的是 $f$、$f'$ 还是 $f''$？
   - $f^{-1}$ 是 inverse function，还是 reciprocal？
   - horizontal tangent 属于哪一个函数？

2. **Structure recognition / 先看最外层 operation**
   - nested function -> [[Chain Rule]]
   - two changing factors -> [[Product Rule]]
   - mixed $x,y$ relation -> [[Implicit Differentiation]]
   - inverse derivative -> [[Inverse Function Derivatives]]

3. **Rule stacking / 多条规则同时出现**
   - $xy^3$ 同时需要 Product Rule 与 Chain Rule。
   - $g(-2x)h(x)$ 同时需要 Product Rule 与 inner derivative $-2$。
   - implicit second derivative 需要再对含 $y$ 与 $y'$ 的表达式求导。

4. **Theorem triggers / 定理触发词**
   - endpoint values + exists $c$ + asks for $f'(c)$ -> [[Mean Value Theorem]]。

5. **Context-to-model translation / 从文字到模型**
   - position / velocity / acceleration 必须先确定对象与导数层级。
   - related rates 必须先写恒成立的关系，再对时间求导。
   - rate function 的 derivative 表示“rate of the rate”，单位会再除一次时间。

6. **Multiple changing factors / 多个变化因子**
   - 第2次的 $xy^3$ 与第3次的 $t\sin(t^3/100)$、$(t-2)(t-5)e^{-0.2t}$ 都说明 Product + Chain 仍会漏项。

## Error Codes / 错误代码

| Code | 含义 | 处理方式 |
|---|---|---|
| `R` | Recognition：没有认出题型或对象 | 写出触发词，不看答案重选方法 |
| `M` | Method：规则选择错误或漏规则 | 画 outer/inner 或 factor tree |
| `A` | Algebra：符号、指数、移项、代入错误 | 从最后一个正确等式开始重算 |
| `J` | Justification：缺 theorem、条件、单位或语境 | 只补得分句，不重抄整题 |
| `AI` | AI 读错题或给出不可靠推导 | 回到原题，核对符号与选项，不把错误答案写入知识卡 |

## Standard Review Loop / 固定复盘流程

1. 第一次作答只用黑色，不看 AI。
2. 卡住时先写 `R / M / A / J`，说明自己卡在哪一层。
3. AI 只给一个 hint 或按 rubric 指出第一个缺失得分点。
4. 红色只补“缺失连接”，不抄完整解答。
5. 24 小时后无提示重做。
6. 能完成并解释“为什么用这个方法”才标记 `mastered`。

## Mastery Standard / 掌握标准

一道题只有同时满足以下条件才算掌握：

- 能从题目语言识别方法；
- 能独立写出第一行数学关系；
- 能完成计算并检查符号；
- FRQ 能用 2-5 行写出必要证据；
- 隔天能够无提示重做。
