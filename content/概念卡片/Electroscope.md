# Electroscope

## Core Sentence / 核心句

An electroscope detects whether an object is charged by observing leaf separation.

中文理解：验电器能显示是否带电，但通常不能单独直接判断正负。

## Formula / 公式或规则

Qualitative instrument; no core AP formula here.

## When To Use / 什么时候用

看到 leaves spread、charged object nearby、induction demo，就想到 electroscope。

## Watch Out / 易错点

叶片张开说明存在电荷分布变化，不等于直接知道电荷符号。
