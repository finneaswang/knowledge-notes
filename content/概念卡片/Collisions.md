# Collisions
## Core Sentence / 核心句
Momentum is conserved in an isolated collision, while kinetic energy is conserved only in an elastic collision.
## Classification / 分类
- elastic: $P$ and $K$ conserved；
- inelastic: $P$ conserved, $K_f<K_i$；
- perfectly inelastic: objects stick, maximum kinetic-energy loss for the given initial state。
