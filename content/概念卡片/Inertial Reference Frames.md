# Inertial Reference Frames

## Core Sentence / 核心句

Inertial frames move at constant velocity relative to one another, so they measure different velocities but the same acceleration in Galilean mechanics.

中文理解：换到匀速运动的参考系，velocity 会整体平移，但 acceleration 不变。

## Formula / 公式

If $\vec v_{B/C}$ is constant:

$$
\vec a_{A/C}=\vec a_{A/B}
$$

## Watch Out / 易错点

有加速度或旋转的 frame 不是这里默认的 inertial frame，需要引入 non-inertial effects。
