# UBC Concept Index

Editorial note: concept cards prevent high-value Obsidian links from opening as blank pages.

## Link Hygiene Rule / 链接卫生规则

- Use wiki links for concepts that deserve their own review card.
- If a phrase is only a casual wording and not a reusable concept, keep it as plain text.
- When a linked page becomes blank, either fill it as a concept card or remove the wiki link from the source note.
- 高频、跨课程、会复习的概念优先做卡；低频未来章节不要机械造空壳。
