# Vector-Valued Functions

## Core Sentence / 核心句

A vector-valued function packages coordinate functions into one time-dependent position.

$$
\mathbf r(t)=\langle x(t),y(t)\rangle,
\quad
\mathbf v(t)=\mathbf r'(t),
\quad
\mathbf a(t)=\mathbf r''(t).
$$

$$
\text{speed}=\|\mathbf v(t)\|
=\sqrt{[x'(t)]^2+[y'(t)]^2}.
$$

## Watch Out / 易错点

Velocity is a vector; speed is a scalar magnitude. Integrating velocity gives displacement, so final position still requires the initial position.
