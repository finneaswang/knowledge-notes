# Vector Field

## Core Sentence / 核心句

A vector field assigns a vector to every point in space.

中文理解：矢量场是在空间每一点放一个矢量，电场就是典型例子。

## Formula / 公式或规则

$$\vec E(x,y,z)$$

## When To Use / 什么时候用

看到 field map、direction at every point，就想到 vector field。

## Watch Out / 易错点

vector field 不只是大小图，还包含方向。
