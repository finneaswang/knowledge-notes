# Free-Body Diagrams

## Core Sentence / 核心句

A free-body diagram isolates one chosen object and shows only the external forces acting on it.

中文理解：先选研究对象，再把外界对它的每个真实力画出来。

## Procedure / 步骤

1. isolate the object or system；
2. identify every external interaction；
3. draw one arrow for each actual force；
4. label force type and agent；
5. choose axes after seeing the geometry；
6. resolve forces into components in equations, not as replacement force arrows。

## Watch Out / 易错点

- velocity、acceleration、motion path 不是力；
- Newton's third-law partner acts on the other object，不画在同一物体的 FBD 上；
- 分量是数学拆分，不是额外的力。
