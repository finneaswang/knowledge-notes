# Tiny Nudges

## Core Sentence / 核心句

Tiny nudges are small input changes used to understand derivatives and local behavior.

中文理解：微小扰动是理解导数、微元和局部线性变化的直觉工具。

## Formula / 公式或规则

$$dx,\ dE,\ dq$$

all represent tiny pieces or tiny changes in different contexts.

## When To Use / 什么时候用

看到 small change、differential、local linear behavior，就用 tiny-nudge thinking。

## Watch Out / 易错点

微小量不能随意当普通数字乱约；要看极限或微分关系。
